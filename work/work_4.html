ポートフォリオサイト（本Webサイト）

依頼主
自分
仕様
HTML / CSS / jquery、レスポンシブ対応

本サイトを作るにあたり、本サイトのテーマとなる名刺のデザインを考えました。下の名前の「みのり」から果物（実）のモチーフを取り入れ、自分らしく、「シンプル」「優しさ・柔らかさ」「ちょっと笑える」ことを目指して全体のレイアウトをしていきました。

そして、ポートフォリオは名刺のようなもの、とよく言われることから、ダイレクトにファーストビューに名刺を差し出してみました。数あるポートフォリオの中でインパクトを感じていただけたら幸いです。どのデバイスで見ても、ファーストビューの範囲は変わらないように工夫しています。また、読みやすさを重視し、全体を見てほしいという思いから、ワンカラム、ワンページのレイアウト構成となっています。
